# カスタム配列タイピング

大西配列・Dvorak・Colemak や自分で作ったキー配列で、日本語（ローマ字入力）と英文のタイピングを練習できるツールです。
ブラウザで開くだけで動きます。インストールやアカウント登録はいりません。
v6 から、画面の後ろの 3D のキーボードが、押したキーに合わせて沈み、光るようになりました。

## はじめかた

1. 公開しているページを、ブラウザ（Chrome / Edge / Firefox / Safari の最新版）で開きます。手元で動かすときは `bash start.sh` を実行します（ファイルをダブルクリックして開く形では動きません）。
2. 初めて開くとチュートリアルが出ます。次の3つを選ぶと準備は終わりです。チュートリアルは右上の「ヘルプ」→「チュートリアルを見る」からいつでも見直せます。
   - キーボードの種類（JIS / US）
   - 練習する配列
   - キーボード側で配列を変えているかどうか
3. **スペースキー**を押すと練習が始まります。
4. 動きが重いときや、パソコンが熱くなるときは、右上の「設定」で「軽い表示」をオンにします。

> チャットアプリやメールのプレビュー画面で開くと、記録が保存されません。保存できない環境では、画面上部に赤い警告が出ます。

## 入力のしくみ（キーマップ）

- 押したキーの**位置**を、選んでいる配列で文字に読み替えて判定します。VIAL でキーに文字を割り当てるのと同じ考え方で、配列エディタで変えた割り当てがそのまま練習に反映されます。
- 普通の QWERTY キーボードのままで、大西配列や自作の配列を練習できます。
- 画面上部の「キーボード」で **JIS / US** を選べます。選ぶと、画面のキーの刻印と、プリセット配列の記号キー（JIS の `@` `:`、US の `[` `'`）が切り替わります。

### キーボード調整
キーボード本体（VIAL / QMK など）や、AutoHotkey・Karabiner で配列を変えているときは、画面上部の「キーボード調整」を一度だけ行ってください。
- 光るキーを順に押すと、「届く信号」と「実際のキーの位置」の対応表が保存されます。キーボード側の設定はそのままで、正しく判定されるようになります。
- OS の「キーボード配列」の設定は判定に影響しないので、こちらは調整しなくて大丈夫です。
- 調整していないのに、ミスの多くが「QWERTY でその文字があるキー」になっているときは、調整をすすめる案内が出ます。
- キーボードを替えたら、もう一度調整してください。「調整を解除」で元に戻せます。
- 調整中は Esc・Backspace も1つのキーとして読み取ります。そのため「1つ戻る」「中止」はボタンで操作します。
- 文字の位置から Esc が届くキーボードでは、練習中に Esc を押すと文字として打たれます。一時停止は画面上部の「一時停止・やり直し」ボタンで行ってください。
- **Shift も調整する（任意）**：キーボード側（QMK のキーオーバーライドなど）で、Shift と一緒に押したときに別のキーを送るようにしている場合に使います。Shift を押したまま光る位置のキーを順に押すと、届いた信号を「その位置を Shift と一緒に押した」と覚えます。キーの位置の調整とは別に、あとからでも行えます（キーの位置をやり直しても Shift の調整は残ります）。標準どおりの信号のキーは記録しません。Shift と一緒に押したときに、別のキーを Shift なしで押したのと同じ信号が届くキーは区別できないため、飛ばしてください。

### Shift で打つ記号
- `!` `?` `(` `)` `"` などは、ふつうのキーボードと同じく Shift と一緒に打ちます。たとえば JIS なら `!` は Shift+1、`"` は Shift+2 です。どの文字になるかは、選んでいるキーボードの種類（JIS / US）で自動的に決まります。
- ガイドでは**左の Shift** が光ります。「設定」→「光らせる Shift」で「右」や「反対の手」に変えられます。
- Shift を押したまま打っても、Shift なしの文字が正解なら正解になります。

### 追加のキー（40% キーボードなど）
数字・記号・Shift を、キーボードのレイヤーや別のキーから打っているときに使います。
- 画面上部の「追加のキー」を開き、表示されたキー（「4」や「Shift」など）を実際に打って登録します。
- `!` `?` など Shift と一緒に打つ記号も登録できます。キーボードの下の「Shift で打つ記号」から1つずつ選ぶか、「！？などをまとめて登録」で続けて登録します。並ぶ記号は、選んでいるキーボードの種類（JIS / US）で変わります。
- 1つのキーに、Shift なしの文字（「2」など）と Shift ありの記号（「?」など）を別々に登録することもできます。
- 登録したキーが、すでにあるキーと同じ信号だったときは、「置き換える」か「押し直す」かを選べます。
- レイヤーそのものは、キーボード側（VIAL など）で設定してください。

## できること

### 3D のキーボード
- 画面の後ろに、机の上のキーボードが 3D で出ます。キーには、選んでいる配列の文字が刻まれます。
- キーを押すと、3D のキーボードでも同じ位置のキーが沈み、指の色で光ります。次に押すキーも光ります（Shift は押している間ずっと沈みます）。
- 練習中以外は、カメラがゆっくり回り込みます。タブごとに、カメラの位置と光の色が変わります。
- 3D のキーボードは **US 配置の形**です。JIS だけにあるキー（¥・ろ）を見たいときは、「設定」の「練習のキーボード」を「平面」にします。
- 「設定」で、テーマ（ダーク・ライト・自動）、運指の色分け、「軽い表示」（影やぼかし、カメラの動きを省いて軽くする）を変えられます。
- パソコンの「視差効果を減らす（動きを減らす）」設定がオンのときは、キーは沈まず、カメラも動きません。

### タイピング練習
- 問題文・よみがな・ローマ字が表示されます。打った文字はオレンジ色になり、次に打つ文字にはオレンジの下線が付きます。
- 3D（または平面）のキーボードと指のガイドが、次に押すキーと使う指を示します。
- **ローマ字方式**は、日本式（し＝SI）とヘボン式（し＝SHI）を切り替えられます。どちらを選んでいても、別の綴り（SI / SHI / CI など）で打てば正解になります。
- 「シェ」「チェ」「ジェ」「ヴァ」「ツァ」などの外来語の音も、ふつうの綴り（SHE / SYE、CHE / TYE、JE / ZYE、VA、TSA など）で打てます。
- 記号は、ふつうのローマ字入力と同じキーで打ちます（ー＝`-`、、＝`,`、。＝`.`、・＝`/`、「＝`[`、」＝`]`、！＝Shift+1 など）。今の配列のどのキーでも打てない記号は、自動で飛ばします。
- 右上の「設定」で、次の表示をそれぞれ変えられます。
  - テーマ（ダーク・ライト・自動）
  - 練習のキーボード（3D・平面）
  - 軽い表示（影やぼかし、カメラの動きを省いて軽くする）
  - 運指の色分け
  - 次のキーのガイド
  - QWERTY の文字を添える
  - よみがな・ローマ字の表示
  - 最小構成（練習中は文とキーボード以外を隠す）
  - 打鍵音
- 練習を終えると、結果の画面にランクが立体の文字で出ます（S 以上は王冠付き）。

### シャトルラン
- 練習画面の「シャトルランに挑戦」から始めます。画面は暗い色になり、レベルに合った長さの文が1つずつ出ます。文を打ち切ると、すぐ次のレベルへ進みます。
- レベル1は、1分に約48打で間に合うペースです。レベルが1つ上がるごとに、必要なペースが8%ずつ（レベル16からは7%ずつ）上がり、文も少しずつ長くなります。
- 長い文が出るレベル18からは、文を読点の位置で2つに、レベル31からは3つに分けて、1つずつ表示します。部分を打ち終えるとすぐ次の部分に進み、次の部分は下に薄く表示されます（「1 / 2」のような表示つき）。制限時間は文全体で1つです。
- シャトルランの文には、文末の「。」とカギカッコ「」は入れていません。
- 制限時間が増えたり減ったりする決まりです。

  | できごと | 時間 |
  |---|---|
  | ミスなしで20打続けるたび | ＋0.5秒 |
  | ミス1回ごと | −0.2秒（同じレベルで4回目からは −0.4秒） |
  | 残った時間 | 30%（最大3秒）を次のレベルへ持ち越し。ノーミスならさらに ＋0.5秒 |
  | ノーミスのレベルを3つ続ける | シールドを1つ獲得（2つまでためられます）。1つで時間切れを1回防ぎます |
  | シールドが発動したあとの3秒間 | **無敵**：時間が減らず、ミスも数えません（そのレベルの間だけ。次のレベルへは持ち越しません） |

- 時間が減るほど、文にひびが入って欠けていきます。時間切れになったレベルが「到達レベル」です。
- 無敵は金色で表示されます（文の枠の上の札と残り秒数・残り時間の帯の縞模様・「無敵」の表示。札は文の枠の外に出るので、文には重なりません）。ローマ字が2行になるときは、2行目が左端から始まります。無敵の間に打ち間違えると「ガード」と出ます。
- **トロフィー**：シャトルランで条件を満たすと、ブロンズ・シルバー・ゴールド・プラチナ・ダイヤモンド・ゴッドのトロフィー（全19個。ゴッドは「神の手」＝レベル40到達の1つだけ）を獲得します。結果画面に「トロフィー獲得！」と出て、「記録」→「シャトルラン」でいつでも見られます。トロフィーは配列に関係なく集まり、シャトルランの記録を削除しても残ります（バックアップにも入ります）。
- **Esc** で一時停止できます。止めている間は時間が進みません。別のウィンドウに移ったときも自動で止まります。
- 記録は配列ごとに「記録」→「シャトルラン」に残ります。通常の練習のスコアや難易度補正には入りません。平均の速さ（打/分）は、無敵の時間を除いて計算します。
- 各レベルの文の長さと制限時間は「レベル一覧」で見られます。待機画面、結果画面、操作ガイドのどこからでも開けます。

### 練習文の編集
- **プリセット**は練習文のまとまりです。
  - 文章を何行かまとめて貼り付けると、1行1文のリストになります。漢字はよみがなとローマ字に自動で変換されます。変換がまちがうこともあるので、確認してください。
  - 変換のようすは、「リスト操作と一括自動変換」の欄の「変換ログ」で確かめられます。漢字→かなの変換とローマ字への変換が、コマンドライン風に流れて表示されます。最新の 300 行まで表示し、それより古い行は自動で消えます（「クリア」でいつでも消せます）。
  - 貼り付けたあとは「新規プリセットに保存」で、新しいプリセットとして保存できます。
  - **自動改行**：貼り付け欄の下の「自動改行」で、**短（6文字）・中（12文字）・長（18文字）**ごとに改行できます。文字数は貼り付けたまま（漢字かな変換の前）で数え、空白は数えません。余りが半分より多ければそのまま1行にし、少なければ前の行に1文字ずつ（足りなければ2文字ずつ）振り分けます。熟語の途中や「っ」「ー」「、」の前では、なるべく区切りません。
  - **記号を削除**：「」、。！？・〜 などの記号をまとめて取り除きます（長音の「ー」は残ります）。記号だけの行はなくなります。
  - 自動改行したあとにほかの長さを選ぶと、改行する前の文から改行し直します（「元に戻す」を押さなくてもボタン1つで変えられます）。
  - 記号も1文字として数えるので、**記号の削除は自動改行の前**に行うのがおすすめです。
  - 自動改行と記号の削除は、結果が「変換ログ」に出ます。「元に戻す」で1つずつ戻せます。「問題文|よみ」「問題文（よみ）」の形の行はそのままにします。
  - **リストから戻す**：貼り付け欄の下の「リストから戻す」で、今のプリセットの文を1行1文で欄に戻せます。欄で直してから「リスト上書き保存」で置き換えたり、「新規プリセットに保存」で別のプリセットにしたりできます（貼り付け直したときに漢字かな変換し直します）。
  - **欄をクリア**：貼り付け欄の文をすべて消します。リストから戻すと同じく、欄にあった文は「元に戻す」で戻せます。
  - 「問題文|よみ」「問題文（よみ）」の形で貼り付けた行は、書いたよみをそのまま使います（漢字かな変換し直しません）。
  - **変換辞書**：漢字かな変換でうまく読めなかった言葉は、「変換辞書」に言葉と正しいよみを登録すると、次から登録したよみで変換されます（内蔵の辞書や形態素解析より優先）。よみがなを手で直すと、その行に「辞書に登録：言葉 → よみ」が出るので、押すとそのまま登録画面に入ります。登録したあと「当てはめる」を押すと、今のプリセットでその言葉を含む文を変換し直します。1文字の言葉を登録すると、その文字を含むすべての文で使われるので注意してください。登録した言葉はブラウザに保存され、バックアップにも入ります。
    - 言葉は、問題文の中の**一字一句同じ部分**（送り仮名も含めて）に使われます。前から順に探し、同じ位置から始まる言葉がいくつもあるときは長いほうを使います。
    - 送り仮名つきで登録した言葉（例：憚る → はばかる）は、「憚らない」「憚った」のような**活用した形**にも使われます（形態素解析で活用だと分かったとき。「憚」のように解析の辞書にない漢字は、漢字のあとにひらがなが続くとき）。
    - 「直す」で開いた登録は「更新」で置き換わります。「憚る → はばかる」は最初から登録してあります（直したり削除したりできます）。
    - くわしい仕様は、変換辞書の画面の「くわしい仕様」にあります。
  - プリセット1（いろは歌）・プリセット2（夏目漱石『こころ』冒頭）・プリセット3（日常）は標準のプリセットです。前の版から使っているときは、プリセット3 が自分のプリセットのあとに足されます（名前の番号は並びに合わせて付きます）。文の編集はできますが、削除はできません。「初期文に戻す」で元の文に戻せます。
  - 「保存済みのプリセット」のカードをドラッグすると、プリセットの順番を入れ替えられます（スマホやタブレットは長押ししてから動かします。カードを選んで Shift + ← / → でも動かせます）。「保存する」で確定し、「一つ前に戻る」で戻せます。標準のプリセットも動かせます。カードはすべて同じ大きさで並びます。
  - プリセットが多くて4段以上になるときは、カードが小さくなり、1段に並ぶ数が増えます（2段階）。
  - 自分のプリセットは「＋ 新規追加」で作れます。種類を「英文」にすると、英語の文章をそのまま練習できます。スペースも1文字として打ち、大文字と小文字は区別しません。
  - 各行の左端をドラッグすると、文の順番を入れ替えられます。
- **グループ（プレイリスト）**は、いくつかのプリセットをまとめたものです。
  - 練習画面上部の「練習文」でグループを選ぶと、入っているプリセットを続けて練習できます。結果画面でスペースキーを押すと次へ進みます。
  - グループ内のプリセットの順番も、ドラッグで入れ替えられます。
  - 練習の順番は次の3つから選べます。
    - **順番に**：グループに並べた順で練習します。
    - **シャッフル**：プリセットの順番をランダムにします。
    - **全シャッフル**：グループ内のすべての文を、プリセットをまたいで混ぜます。1回に練習する文の数は、プリセット1つ分の平均です。記録は「グループ名（全シャッフル）」としてまとめて残ります。
  - シャッフルと全シャッフルは、ボタンを押すたびに順番を引き直します。一周したときも新しい順番になります。
- **文の順番をシャッフル**：練習画面の待機中にオンにすると、練習のたびに文の順番がランダムになります。練習文の並びは変えず、設定も保存しません。
- 変更は「保存する」ボタンで確定します。「一つ前に戻る」ボタンか Ctrl+Z で、段階的に元に戻せます。

### 配列エディタ（VIAL 式）
- キーボード上のキーをクリックするか、実際にそのキーを押して選び、下の一覧から文字を選ぶと割り当てられます。Shift キーも、ほかの文字キーと同じように押せば選べます。選んでいるキーは矢印キーで動かせます。
- **割り当てたら次のキーへ進む**（オン / オフ）：オンにすると、左上から順に続けて割り当てられます。
- **使用中の文字は入れ替える**（オン / オフ）
  - オンのときは、別のキーにある文字を選ぶと、2つのキーの文字が入れ替わります。同じ文字が2か所になったり、文字がなくなったりしません。
  - オフにすると上書きになります（VIAL と同じ動き）。文字が重なったキーには赤い印が付きます。
- キー同士をドラッグすると入れ替わります。一覧の文字をキーへドラッグすると、直接割り当てられます。担当する指も変えられます。
- **Shift と一緒の文字**：一覧の上の「通常 / Shift と一緒」を「Shift と一緒」にすると、キーを Shift と一緒に押したときの文字を、キーごとに決められます（例：`,` の位置の Shift を `!` にする）。決めていないキーは薄い文字で表示され、コンピューターの Shift と同じ文字（JIS なら 1 → `!`）になります。「このキーを自動に戻す」「すべて自動に戻す」で元に戻せます。決めた文字は、通常の面のキーの左上に小さく `⇧!` のように表示され、練習の判定とガイドにも使われます。.ahk に書き出すときは、Shift の割り当ては AutoHotkey v2 用の行（`+キー::SendText "文字"`）としてコメントで出力します（v1 と v2 で書き方が違うため）。
- 一覧の下には、ローマ字入力に必要な文字（A〜Z・ー・、。）のうちまだ置いていないものと、2つ以上のキーにある文字が表示されます。
- 配列の一覧には、プリセット（大西配列・QWERTY・Dvorak・Colemak）と5つの保存枠が並んでいます。プリセットは上書きされません。編集して「保存枠に保存」を押すと、「現在の配置を別枠へ保存」で選んだ保存枠に保存されます。
- 配列は **JSON** と **AutoHotkey（.ahk）** で読み込み・書き出しができます。.ahk は Windows で、このツールの外でも実際のキーボードを並べ替えるのに使えます。AutoHotkey を動かしたまま練習するときは、「キーボード調整」をしてください。
- 下の「配列分析」で、次の4つを確認できます。
  - ホーム段の使用率
  - 左右の手のバランス
  - 左右交互打鍵率
  - 同じ指の連続率

  「実測」は実際に正しく打ったキーの集計です。「理論値」は、選んでいる練習文をガイドどおりに打った場合の計算です。

### 記録
- 最後まで打ち切った回だけが記録されます。
- スコア・WPM・文字/分・正確率・リズムの推移を、グラフで見られます。
- **配列ごとに色が決まっています**。大西配列はオレンジ、QWERTY は青、Dvorak は緑、Colemak は紫です。自分の配列には、ピンク・黄・濃い緑・赤を、記録に初めて出てきた順に割り当てます。色が足りない9つ目からの配列は灰色になります。「配列別のスコア」の棒グラフも、同じ色で表示します。
- 「すべての配列」を選んでいるときは、最初は配列ごとに別々の折れ線を1つのグラフにまとめて表示します。「まとめて1本」に切り替えると、すべての配列の推移を濃いグレーの1本で、5回移動平均つきで表示します。
- 配列・練習文・期間（直近20回 / 50回 / 100回 / すべて）で絞り込めます。
- グラフの横軸には、回の番号（#1 など）の下に練習した日付が出ます（同じ日が続くときは最初の1つだけ。年をまたぐときは年も）。日が変わるところには薄い縦の線が入ります。グラフの下の「横軸に日付を表示」でオフにできます（設定は保存されます）。
- すべての練習文をまとめて見るときは、「難易度補正」をオンにすると、練習文ごとの点の取りやすさをそろえて公平に比べられます。「練習文ごとの得意・不得意」も表示されます（スコアが出にくい練習文は苦手な文、出やすい練習文は得意な文と考えられます。練習文そのものの難しさも含みます）。点の取りやすさは配列ごとに別々に計算します（同じ練習文でも、配列によって打ちやすさが変わるため）。「すべての配列」のときは、得意・不得意を配列ごとに分けて並べます。
- 「シャトルラン」タブでは、シャトルランの記録が配列ごとに見られます。

## スコアとランク

```
スコア = はやさ × せいかくさ × リズム
       = (標準打鍵/分 ÷ 1.7 × 10) × (正確率の3乗) × (0.7〜1.0)
```

| 要素 | 意味 |
|---|---|
| はやさ | 練習文を標準のローマ字（日本式）で打つと何打鍵になるかを基準にした速さです。打ちにくい文でも、ヘボン式で打っても損をしません。英文は1文字＝1打鍵で計算します |
| せいかくさ | 押したキーのうち正しかった割合です。3乗するので、ミスが多いと大きく下がります（95%→×0.857、90%→×0.729） |
| リズム | キーの間で立ち止まった打鍵（ふだんの間隔の2倍以上かかった打鍵）が少ないほど高くなります（立ち止まり10%→×0.9、下限は×0.7） |

ランクは **E から SSS までの18段階**です（E、D-〜D+、C-〜C+、B-〜B+、A-〜A+、S-〜S+、SS、SSS）。基準の表は、操作ガイドか結果画面の「ランク一覧」で見られます。WPM は「正打鍵数 ÷ 5 ÷ 分」で計算します。

## データの保存とバックアップ

- 練習文・配列・スコア・シャトルランの記録・設定は、**使っているブラウザの中**に自動で保存されます。ファイルやブラウザを閉じても残ります。
- 次のときは、データが見えなくなる（消える）ので注意してください。
  - 別のブラウザや別のパソコンで開いたとき
  - ブラウザの閲覧履歴やサイトデータを削除したとき
  - シークレット（プライベート）ウィンドウで開いたとき
  - サイトの URL（置き場所）が変わったとき
- 右上の「データ」で、次のことができます。
  - **バックアップを書き出す**：全データを1つの `.json` ファイルにします。別のパソコンやブラウザでも「バックアップから復元」で読み込めます。
  - **以前のバックアップファイルを選んで上書き保存**：新しいファイルを増やさずに、パソコンにある以前のバックアップファイルを、今のデータで書き換えます。選べるのはこのツールのバックアップファイルだけで、中身を確かめてから書き込みます。一度選んだファイルは覚えておくので、次からはボタン1つで上書きできます。この機能は Chrome / Edge で使えます。ほかのブラウザでは「バックアップを書き出す」を使ってください。
    - **関係のないファイルを選んだとき**は、「このファイルは使えません」という赤い注意のポップアップが出ます。ファイル名と理由（このツールのバックアップではない、JSON として読めない、大きすぎる など）が表示され、ファイルは書き換えません。覚えていたファイルの中身がバックアップでなくなっていたときは、そのファイルを忘れて、次からは選び直すようにします。「バックアップから復元」で関係のないファイルを選んだときも同じポップアップが出て、今のデータはそのまま残ります。ポップアップは「閉じる」・Esc・Enter で閉じられます。
  - **ブラウザの保存容量**：このツールがどれだけ容量を使っているかを、種類別に確認できます。
  - **大きなデータの圧縮**（はじめはオフ）：練習文やスコアの記録が大きくなったら、圧縮して容量を減らせます。内容は変わらず、バックアップは圧縮せずに書き出します。圧縮すると、この機能がない古い版のツールを同じブラウザで開いたときに、圧縮した記録を読めなくなります。
  - **すべてのデータを削除**：このツールが保存したデータをまとめて消し、初めて開いた状態に戻します。確認で「はい」を押したときだけ削除します。
- **バックアップのおすすめ**：前回のバックアップから完走が20回たまったとき、または1週間たって記録や保存が増えたときに、結果画面か待機画面でお知らせします。練習中には出ません。「データ」画面でオフにできます。
- 練習文の編集と配列エディタは、「保存する」ボタンで確定します。保存しないまま移動しようとすると、確認が出ます。

### 以前の版のバックアップについて
- 以前の版（名前が「カスタム配列タイピング練習」だったころのもの）で書き出したバックアップも、そのまま「バックアップから復元」で読み込めます。読み込めることは確認済みです。
  - 配列の保存枠（名前とすべてのキー）
  - 練習文・グループ
  - スコア記録
  - 設定・キーボードの種類・ローマ字方式・キーボード調整
  - 最後に使った配列と練習文
- 復元すると、今のデータはバックアップの内容に**すべて置き換わります**。以前の版のバックアップには、シャトルランの記録・追加のキー・ガイドの Shift の設定は入っていないため、これらは初期の状態になります。圧縮の設定もオフに戻ります。
- 「以前のバックアップファイルを選んで上書き保存」でも、以前の版のバックアップファイルを選べます。

## 通信とプライバシー

- **集める情報はありません。** アカウント登録はいらず、氏名やメールアドレスなどの個人情報を求めることもありません。アクセス解析・広告・Cookie によるトラッキングも使っていません。
- 入力した文字や記録は、このパソコンのブラウザの中（localStorage）にだけ保存されます。上書き保存に使うファイルの場所は、ブラウザ内の IndexedDB に保存します。作成者を含め、だれかに送られることはありません。
- 外部との通信は、次の2種類だけです。どちらも、ふつうのウェブページを見るときと同じように、IP アドレスやブラウザの種類が各サービスに届きます。入力した文章や記録は送りません。
  - 画面のフォントを Google Fonts（fonts.googleapis.com / fonts.gstatic.com）から読み込みます。オフラインでも動きますが、フォントは端末の標準のものになります。
  - 「漢字をかな自動変換」を使ったときだけ、変換のプログラムと辞書（kuromoji 0.1.2）を jsDelivr から読み込みます。つながらないときは unpkg から読み込みます。変換はこのパソコンの中で行います。オフラインでは、内蔵の小さな辞書で変換できる分だけ変換します。
- ページには読み込み先の制限（Content-Security-Policy）を入れてあり、上のサービス以外とは通信できません。
- 動くプログラムも制限しています。このサイト自身のプログラムと、照合済みの変換プログラムだけが動きます。読み込んだファイルなどに仕掛けが紛れ込んでいても、プログラムとしては動きません。
- **配信元（CDN）が改ざんされたときの対策**
  - 変換のプログラムと辞書の12ファイルは、本来のファイルの SHA-256 と1バイトまで一致したときだけ使います。一致しないものは使わずに次の配信元を試し、どこからも使えなければ内蔵の辞書で変換します。
  - フォントの設定ファイルは、中身がフォントの指定だけであることを確かめてから有効にします。
  - 一致しない・想定外の内容だったときは、画面上部に赤いお知らせを出します。外部ファイルの状態は「データ」画面で確認できます。
- 読み込んだファイル（配列・バックアップ）の文字は、画面に表示するときにすべて文字として扱います。プログラムとして動くことはありません。
- プライバシーポリシーの全文は、チュートリアルと操作ガイド（「ヘルプ」→「操作ガイド」）に載っています。

## 注意点・制限

- 平面のキーボードは、実物の JIS / US キーボードと同じ並びとキーの幅で表示します。Tab・Enter・Ctrl などは位置の目安として表示しているだけで、練習では使いません。3D のキーボードは US 配置の形です。
- 漢字まじりの問題文では、問題文の行のオレンジ色の範囲はおおよその位置です。よみがなとローマ字の行は正確です。
- 文が短い（立ち止まりを判定できる打鍵が10未満）ときは、リズムは「計測なし」になり、×0.9 で計算します。
- 難易度補正は、近い時期にいくつかの練習文で練習した記録がたまるほど正確になります。データが少ないうちは補正はかかりません。
- 練習文ごとの出やすさは、その回の前後にほかの練習文で練習した回と比べて決めます（前後の両方にあれば両方から、使い始めたばかりの練習文のように片方にしかなければ、その側の伸び方から「その時点の実力」を推し量って比べます）。そのため、伸びている最中に新しい練習文を始めても、その文が易しいと判断されて最近の伸びが小さく見えることはありません。
- スマートフォンでも表示はできますが、物理キーボードでの練習を前提にしています。
- 動作は Chrome（Chromium）で確認しています。

## 作り直すとき（開発用）

くわしい手順（道具の入れ方、チェック、版番号の決め方、うまくいかないとき）は `開発手順.md` にあります。

- 中身は Rust で、`wasm-pack` で WebAssembly にします。画面は Vite でビルドします（`cd web && npm run build`）。
- `bash check.sh` で、Rust のテスト（v5 と同じ答えになるか 8 万件の照らし合わせ）、画面のビルド、ブラウザでの通し確認、v5 のバックアップの引き継ぎまで、まとめて確かめます。
- 版番号（セマンティックバージョニング：MAJOR.MINOR.PATCH）は `web/package.json` に書き、git のタグで残します。番号の上げ方は `開発手順.md` の G にあります。
- ページには読み込み先とプログラムの制限（Content-Security-Policy）を入れてあります（ビルドのときに `web/vite.config.js` が入れます）。
